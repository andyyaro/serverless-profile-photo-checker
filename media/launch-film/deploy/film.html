One question: is this usable as a profile photo? And with two people in frame, which face is it about?

This is the serverless profile-photo checker.

A small client encodes the photo and posts it to API Gateway. The gateway hands it to a Lambda function. It asks Amazon Rekognition to describe the faces it finds. Unless there is exactly one, it answers: please upload a picture with only one face.

One face passes only if it's smiling and its eyes are open. Anything else comes back as a bad profile photo.

Its role allows three log actions and read-only Rekognition, nothing else.

Fourteen Terraform resources build all of it, and terraform validate passes. It builds on an AWS example, adding the one-face check and the photo rule.
