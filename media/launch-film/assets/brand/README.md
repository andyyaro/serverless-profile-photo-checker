# Brand

The project has no brand: the repo (andyyaro/serverless-profile-photo-checker @fd8589e) holds no logo, mark,
colours, fonts, favicon or site, and Andy's notes name none. There is nothing to copy here.

The film uses the reference look's defaults (HIG Native, as in the CERFODES architecture video): the system face,
the grouped background and the system colours. Its mark is a film-only glyph tile built in the build stage from
the HIG Native icon set (person.crop.circle, white, on a system-blue rounded square, with a small green
checkmark.circle.fill badge). It is not presented as a project logo and is not added to the repo.
